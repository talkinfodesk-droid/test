# 영어 단어 학습 서비스 - 사이트맵 설계

## 1. 전체 사이트맵

```
서비스
├─ 메인
│  ├─ 서비스 소개
│  ├─ 로그인
│  └─ 회원가입
│
├─ 사용자 영역
│  ├─ 학습 홈
│  │  ├─ 현재 월차
│  │  ├─ 현재 난이도
│  │  ├─ 오늘의 학습 시작
│  │  ├─ 최근 학습 요약
│  │  └─ 저장 단어 수
│  │
│  ├─ 문제풀이
│  │  ├─ 문제 보기
│  │  ├─ 첫 답안 제출
│  │  ├─ 뜻 1회 보기
│  │  ├─ 재도전 1회
│  │  └─ 다음 문제 이동
│  │
│  ├─ 결과 보기
│  │  ├─ 총 문제 수
│  │  ├─ 정답 수
│  │  ├─ 오답 수
│  │  ├─ 저장 단어 수
│  │  ├─ 학습 홈으로 이동
│  │  └─ 내 단어장으로 이동
│  │
│  ├─ 내 단어장
│  │  ├─ 단어 목록
│  │  ├─ 최근 저장순
│  │  ├─ 많이 틀린 단어
│  │  ├─ 난이도별 보기
│  │  ├─ 주제별 보기
│  │  └─ 단어 상세 이동
│  │
│  ├─ 단어 상세
│  │  ├─ 영어 단어
│  │  ├─ 뜻
│  │  ├─ 예문
│  │  ├─ 예문 뜻
│  │  ├─ 난이도
│  │  └─ 주제
│  │
│  └─ 마이페이지
│     ├─ 닉네임
│     ├─ 가입일
│     ├─ 학습 시작일
│     ├─ 현재 월차
│     ├─ 현재 난이도
│     ├─ 누적 학습 수
│     └─ 저장 단어 수
│
└─ 관리자 영역
   ├─ 관리자 로그인
   │
   ├─ 대시보드
   │  ├─ 총 사용자 수
   │  ├─ 오늘 학습 사용자 수
   │  ├─ 등록 문제 수
   │  ├─ 등록 단어 수
   │  └─ 평균 정답률
   │
   ├─ 문제 관리
   │  ├─ 문제 목록
   │  ├─ 문제 검색
   │  ├─ 난이도 필터
   │  ├─ 주제 필터
   │  ├─ 문제 등록
   │  ├─ 문제 수정
   │  └─ 문제 비활성화
   │
   ├─ 단어 관리
   │  ├─ 단어 목록
   │  ├─ 단어 검색
   │  ├─ 난이도 필터
   │  ├─ 주제 필터
   │  ├─ 단어 등록
   │  └─ 단어 수정
   │
   ├─ 사용자 관리
   │  ├─ 사용자 목록
   │  ├─ 가입일 확인
   │  ├─ 현재 월차 확인
   │  ├─ 현재 난이도 확인
   │  └─ 마지막 학습일 확인
   │
   └─ 통계
      ├─ 전체 평균 정답률
      ├─ 자주 틀린 문제
      ├─ 자주 틀린 단어
      └─ 최근 학습 추이
```

## 2. 사용자 기준 메뉴 구조

### 로그인 전

| 메뉴 | 경로 |
|------|------|
| 메인 | `/` |
| 로그인 | `/login` |
| 회원가입 | `/signup` |

### 로그인 후

| 메뉴 | 경로 |
|------|------|
| 학습 홈 | `/home` |
| 내 단어장 | `/vocabulary` |
| 마이페이지 | `/mypage` |

### 학습 중 흐름

```
학습 홈 → 문제풀이 → 결과 보기 → 내 단어장
/home    /quiz      /result      /vocabulary
```

## 3. 관리자 기준 메뉴 구조

| 메뉴 | 경로 |
|------|------|
| 대시보드 | `/admin` |
| 문제 관리 | `/admin/questions` |
| 단어 관리 | `/admin/words` |
| 사용자 관리 | `/admin/users` |
| 통계 | `/admin/stats` |

## 4. MVP용 최소 사이트맵

### 사용자 (6개 화면)

- 로그인
- 회원가입
- 학습 홈
- 문제풀이
- 결과 보기
- 내 단어장

### 관리자 (4개 화면)

- 관리자 로그인
- 대시보드
- 문제 관리
- 단어 관리

## 5. 네비게이션 구조

### 사용자 하단 메뉴 (3개)

| 아이콘 | 메뉴 | 설명 |
|--------|------|------|
| 📖 | 학습 홈 | 학습 시작 및 현황 확인 |
| 📝 | 내 단어장 | 저장한 단어 복습 |
| 👤 | 마이페이지 | 내 정보 및 학습 통계 |

### 관리자 사이드 메뉴 (5개)

| 메뉴 | 설명 |
|------|------|
| 대시보드 | 서비스 현황 요약 |
| 문제 관리 | 문제 CRUD |
| 단어 관리 | 단어 CRUD |
| 사용자 관리 | 사용자 조회 |
| 통계 | 학습 데이터 분석 |

## 6. 핵심 사용자 이동 경로

```
메인 → 로그인 → 학습 홈 → 오늘의 학습 시작 → 문제풀이 → 결과 보기 → 내 단어장 복습
 /      /login    /home       (버튼)           /quiz      /result     /vocabulary
```

이 동선이 서비스의 핵심 플로우입니다.
